# Лабораторная работа 1. Линейная регрессия

## Тема
Построение и оценка моделей линейной регрессии (обычная, Lasso, Ridge) на реальных метеоданных. Анализ мультиколлинеарности и снижение размерности методом PCA.

## Датасет
Ежедневные наблюдения станции **Варшава-Окенце** (1993–2022), 10 954 дня.  
Целевая переменная — среднесуточная температура воздуха (`TAVG`, °C).  
Признаки: год, месяц, день года, сезонные компоненты (`sin`/`cos`), осадки (`PRCP`), высота снега (`SNWD`).

## Что сделано
- первичный анализ и визуализация распределений;
- проверка зависимостей (корреляции, диаграммы рассеяния);
- расчёт VIF, выявление мультиколлинеарности;
- обучение Linear / Lasso / Ridge, метрики RMSE, R², кросс-валидация;
- анализ остатков (гомоскедастичность);
- PCA (5 компонент, ~96 % дисперсии) и сравнение качества моделей до/после.

## Основные результаты
| Модель | RMSE (°C) | R² |
|--------|-----------|-----|
| Linear / Ridge | 3.80 | 0.81 |
| Lasso | 3.82 | 0.81 |
| После PCA | 3.89 | 0.80 |

Сезонность (`cos_doy`) — главный предиктор температуры. После PCA качество снизилось незначительно, мультиколлинеарность устранена.
